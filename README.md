## 과학적 범위

밀도·점성이 일정한 비압축성 뉴턴 유체를 교육 목적으로 근사합니다.

```math
\frac{\partial \mathbf u}{\partial t} + (\mathbf u\cdot\nabla)\mathbf u
= -\frac{1}{\rho}\nabla p + \nu\nabla^2\mathbf u + \mathbf f,
\qquad \nabla\cdot\mathbf u = 0
```

- 2차원 균일 격자, 반라그랑주 이류, 암시적 점성 확산, 압력 투영을 사용합니다.
- 벽은 비관통·자유 미끄럼 경계를 근사합니다. 압력 투영은 유한 반복이라 잔여 발산이 있습니다.
- 색 잉크는 수동 추적자이며 시각적 잔상 소멸을 위한 감쇠를 적용합니다. 물의 양을 뜻하지 않습니다.
- 격자 보간에 의한 수치적 확산도 있습니다. 점성·힘은 비교용 무차원 값입니다.
- 실제 물·꿀의 측정값이나 공학 설계용 CFD가 아니며, 3차원 난류 또는 밀레니엄 문제의 증명 결과를 재현하지 않습니다.
- 발산 그래프는 `y = 1/(1−t)`라는 별도 예시 함수입니다. 실제 Navier–Stokes 해와 구분해 표시합니다.

## 3D 시각화의 정확한 범위

3D 세계 좌표의 기둥·곡선·입자를 회전하고 깊이순 정렬과 원근 투영으로 Canvas에 그립니다. 서버·외부 CDN·WebGL 라이브러리 없이 GitHub Pages에서 작동합니다.

- 논문 **2절·그림 1**의 핵심 영역과 중심부의 안쪽 나선 흐름·위아래 유출을 설명합니다.
- `τ = 1 − t`, 허용 범위 안의 예시 지수 `h = 0.005`를 사용해 논문의 **선도항 스케일 관계**를 비교합니다.
- 반지름은 `τ^(1/2)`, 높이는 `τ^(1/2−h)`, 대표 회전·축 방향 빠르기는 `τ^(−1/2−h)`에 비례합니다. 표시에서는 비례상수와 시작값을 1로 정규화합니다.
- 핵심 영역의 부피 × 빠르기²는 `τ^(1/2−3h)`에 비례하므로, 속도가 커지는 동시에 그 영역의 에너지 척도는 작아질 수 있습니다. 전체 유체 에너지와는 구분합니다.
- 시간 슬라이더는 `τ = 10^(−4q)`, `0 ≤ q ≤ 1`로 1에 가까운 변화를 자세히 표시합니다. 마지막 화면도 `t = 0.9999 < 1`이며 모든 표시값은 유한합니다.
- 크기 비교는 같은 눈금을 사용합니다. 핵심 영역 확대 모드에서는 카메라가 축소를 따라 확대하며, 실제 크기 감소는 막대·수치·작은 비교 그림에 남겨둡니다.
- 입자 경로·화살표·주변 보정 고리는 개념을 위한 도식입니다. 애니메이션 속도는 제한합니다. 정지 상태에서 흐름이 형성되는 초기 과정은 생략합니다.
- **실제 3D Navier–Stokes 해, 논문의 입자 궤적, 매끄러운 외력 구성, 증명의 수치 재현이 아닙니다.** 단순한 수축 소용돌이만으로는 논문이 요구하는 매끄러운 외력을 얻을 수 없습니다.

## 로컬 실행

외부 라이브러리·API 키·설치·빌드가 필요 없는 정적 HTML/CSS/JavaScript 프로젝트입니다.

```bash
python -m http.server 8000 --directory dist
```

브라우저에서 `http://localhost:8000`을 엽니다. `dist/index.html`을 직접 열어도 동작합니다.

## 검증

```bash
node --test tests/physics.test.cjs tests/models.test.cjs
```

정지 유체의 보존, 압력 투영, 점성에 따른 에너지 감소, 지속 외력에서 유한한 계산값을 확인합니다. 추가로 교육용 속도장의 비압축성, 힘·변위 관계, 물길의 유량 보존, 3D 핵심 영역의 축소·속도 증가·에너지 척도 감소, 카메라 회전·투영, 잉크의 주기적 이동을 확인합니다. **10개 검증을 통과했습니다.**

JavaScript 문법, 내부 링크, UI 요소 연결, 모든 로컬 자산 경로를 확인했습니다. 모바일에서는 실험과 제어판을 세로로 배치하고 터치·키보드 입력, 모션 감소 설정, 화면 밖 애니메이션 정지를 지원합니다. 새 시각화의 실제 iOS/Android 기기 및 브라우저 화면 검증은 수행하지 않았습니다.
